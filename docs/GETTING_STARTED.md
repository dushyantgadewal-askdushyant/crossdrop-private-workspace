# Getting Started with CrossDrop

## Before you begin

Install CrossDrop on both devices. For the current early-access release, use a
Windows PC and/or Android phone connected to the same private local Wi-Fi or
LAN.

CrossDrop needs no account and does not require a cloud drive.

## Connect two devices

1. Open CrossDrop on both devices.
2. On **Devices**, select the other online device.
3. If the device is not visible, use **Show my QR** on Windows or **Scan QR**
   on Android. You can also use **Join with code**.
4. Compare the verification code shown on both devices. Pair only when the
   codes match and you recognise the other device.
5. The device is then stored as trusted on this device. You can review, rename,
   or forget it from **Trusted devices**.

## Send files

1. Open the recipient's workspace.
2. Drag files into the file area, or select **Browse files**.
3. Review the staged list and select **Send all**.
4. The receiving device reviews the incoming request and accepts or rejects it.
5. Follow progress in **Activity**. Received files are stored in CrossDrop's
   device-organised receipt folder and can be opened from the app.

## Send a message or link

1. Open the recipient's workspace.
2. Enter the text in the secure message composer.
3. Send with the on-screen button. On Windows, Enter sends and Shift+Enter adds
   a new line.
4. The first trusted conversation verification for the day may ask both people
   to compare a code. Later messages that day retain encrypted transport
   without repeatedly showing the code.

## Android while minimized or locked

For incoming pairing, message, and file requests while Android is minimized or
locked:

1. Open **Settings** in CrossDrop.
2. Enable **Keep CrossDrop ready while minimized**.
3. Allow Android notification permission.
4. Keep the quiet "CrossDrop is ready" system notification enabled.

Use **Keep running** when leaving the app if you want it available in Recents.
Use **Exit** when you want to stop local discovery and notification readiness.

## If a device is offline

- Confirm CrossDrop is open or Android keep-ready is enabled on the other
  device.
- Confirm both devices use the same private local network. A router extender,
  guest network, client isolation, or a different subnet can block direct
  connections even when internet access works.
- Refresh Devices, then use QR pairing if nearby discovery remains unavailable.
- See [Troubleshooting](TROUBLESHOOTING.md) before sharing logs or screenshots.

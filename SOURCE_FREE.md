# Source-free public repository boundary

This directory is the complete candidate content for CrossDrop's public GitHub
repository. It intentionally excludes:

- Flutter/Dart and native application source;
- reusable protocol and cryptography implementation details;
- private project architecture, audit, test, and build documents;
- signing certificates, keys, and internal distribution instructions; and
- private Git history.

The private CrossDrop repository remains the authoritative development and
release-build workspace. The public repository should contain only approved
product documentation, approved images, and public release assets.

# Branding assets

Place only approved, redistributable CrossDrop branding here before the public
repository is published.

Recommended files:

- `crossdrop-logo.png` — horizontal logo for the README and social cards.
- `crossdrop-icon.png` — square application/icon mark.
- `crossdrop-social-card.png` — 1280 × 640 px GitHub social preview.

Use the approved CrossDrop infinity-transfer logo. Do not add application
source assets, private design files, or unlicensed third-party artwork.

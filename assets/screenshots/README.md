## Publication review

Before publishing to GitHub, review each image one final time. Do not publish
real local IP addresses, QR or pairing codes, message contents, local paths,
private files, or device labels that have not been explicitly approved for
public display. Prefer neutral demonstration labels and consistent visual
framing when replacing or adding screenshots.
